# PKG Extractor for Android
Android app that extracts PS4 .pkg files (base games, updates, DLC) on-device.

Only PS4 packages are supported. Use it only with packages you own.

## Credits
Extraction code comes from [shadPS4](https://github.com/shadps4-emu/shadPS4) and
[shadPS4Plus](https://github.com/AzaharPlus/shadPS4Plus) (GPL-2.0-or-later).
Includes Crypto++ (Boost license) and fmt (MIT).
Modified for Android: path_util.cpp, log.h, pkg.h, plus the app UI.
